# Webpack 5 Starter Boilerplate

[![Webpack](https://img.shields.io/badge/Webpack-5.x-8DD6F9?style=for-the-badge&logo=webpack)](https://webpack.js.org/)
[![Babel](https://img.shields.io/badge/Transpiler-Babel-F9DC3E?style=for-the-badge&logo=babel)](https://babeljs.io/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg?style=for-the-badge)](LICENSE)

A clean, production-configured Webpack 5 starter boilerplate for modern front-end JavaScript development. Includes automated HTML injection, asset management, and development server with Hot Module Replacement (HMR).

---

## 📦 Features Included
- **Webpack 5 & Webpack Dev Server**: Fast local development server with live reload.
- **Asset Modules**: Native handling of PNG, SVG, JPG images and custom font assets.
- **CSS Loaders**: Configured `style-loader` and `css-loader` for modular stylesheet importing.
- **HTML Webpack Plugin**: Automatic `index.html` generation and script injection.
- **GitHub Pages Deployment Script**: Pre-configured `npm run deploy` via Git subtree push.
